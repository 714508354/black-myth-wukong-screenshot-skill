## 主要功能

- 将任意输入图片重绘为 1920×1080、16:9 的写实游戏画面。
- 保留原图主体、动作、重要物件和内容关系。
- 支持“游玩界面”“得胜界面”“游戏截图”“角色入场”四种模式。
- 在游玩界面中自动选择并置入一名与场景匹配的悟空背影角色。
- 在游戏截图模式中由用户决定是否置入人物。
- 严格引用预设 PNG 界面素材，不自行设计或补画操作 HUD。
- 在存在明确独立敌方主体时，按固定参数生成白色 Boss 血条。
- 支持多图按原顺序逐张处理，不拼成组图。

## 使用方法

### 1. 上传图片并调用技能

上传一张或多张图片，然后输入：

```text
@黑神话悟空游戏截图
```

如果没有提前指定模式，技能会询问：

```text
请选择：游玩界面、得胜界面、游戏截图、角色入场。
```

### 2. 选择输出模式

| 模式 | 人物规则 | 界面效果 |
|---|---|---|
| 游玩界面 | 系统自动置入人物素材 | 使用固定操作 HUD；存在独立敌方主体时会增加 Boss 血条 |
| 得胜界面 | 不置入人物素材 | 压暗背景并显示得胜信息，同时替换 Boss 名称 |
| 游戏截图 | 询问是否置入人物 | 只显示左下角 BLACK MYTH WUKONG 水印，不增加战斗 HUD |
| 角色入场 | 不置入人物素材 | 显示右侧毛笔黑条、红色印章和竖排角色名称 |

用户在首次请求中已经说明模式时，技能会直接处理，不再重复询问。
