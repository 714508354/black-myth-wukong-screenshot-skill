# 黑神话悟空游戏截图 Skill 使用说明

将用户上传的照片或图片转换为 16:9 的《黑神话：悟空》式写实东方暗黑动作游戏画面，并根据所选模式融合固定界面素材。

> 本项目为非官方图像处理工作流，与游戏开发商及发行商无关联。游戏名称、截图、界面和角色形象等相关权利归其权利人所有，请在合法授权范围内使用相关素材和生成结果。

## 主要功能

- 将任意输入图片重绘为 1920×1080、16:9 的写实游戏画面。
- 保留原图主体、动作、重要物件和内容关系。
- 支持“游玩界面”“得胜界面”“游戏截图”“角色入场”四种模式。
- 在游玩界面中自动选择并置入一名与场景匹配的悟空背影角色。
- 在游戏截图模式中由用户决定是否置入人物。
- 严格引用预设 PNG 界面素材，不自行设计或补画操作 HUD。
- 在存在明确独立敌方主体时，按固定参数生成白色 Boss 血条。
- 支持多图按原顺序逐张处理，不拼成组图。

## 使用方法

### 1. 上传图片并调用技能

上传一张或多张图片，然后输入：

```text
@黑神话悟空游戏截图
```

如果没有提前指定模式，技能会询问：

```text
请选择：游玩界面、得胜界面、游戏截图、角色入场。
```

### 2. 选择输出模式

| 模式 | 人物规则 | 界面效果 |
|---|---|---|
| 游玩界面 | 必须自动置入一名悟空 | 使用固定操作 HUD；存在独立敌方主体时可增加白色 Boss 血条 |
| 得胜界面 | 不置入人物素材 | 压暗背景并显示得胜信息，同时替换 Boss 名称 |
| 游戏截图 | 询问是否置入人物 | 只显示左下角 BLACK MYTH WUKONG 水印，不增加战斗 HUD |
| 角色入场 | 不置入人物素材 | 显示右侧毛笔黑条、红色印章和竖排角色名称 |

用户在首次请求中已经说明模式时，技能会直接处理，不再重复询问。

### 3. 补充名称或人物要求

- 选择“游戏截图”且未说明人物要求时，技能会继续询问是否置入人物。
- 选择“得胜界面”或“角色入场”时，可以直接提供需要显示的名称。
- 未提供名称但主体明确时，技能会拟定 2—4 个字的中文短名。
- 主体含义不明确时，技能会询问名称，不猜测专有角色名。

## 固定构图规则

### 输出画面

- 统一输出 1920×1080、16:9 横图。
- 输入比例不符时，优先进行主体感知裁切；竖图允许缩小主体并扩展左右环境。
- 不拉伸主体，尽量保留脸部、手脚、动作、关键物件和主体关系。

### 悟空人物位置

游玩界面必须置入人物；游戏截图仅在用户确认后置入人物。

- 脚底中心锚点：X=49%、Y=83%。
- 角色主体高度：约占画面高度的 51%。
- 角色最高点：约为 Y=31%。
- 角色主体最大宽度：约占画面宽度的 14%。
- 主体横向范围：X=40.5%～54.5%。
- 长武器、外伸饰物和阴影不计入主体尺寸。

人物需继承场景的光线、透视、雾气、景深和地面关系，不得出现白边、悬浮或贴纸感。

### Boss 血条位置

仅在游玩界面且原图存在明确独立敌方主体时添加。置入的悟空是玩家角色，不能被识别为 Boss。

- 中心锚点：X=50.6%、Y=84.5%。
- 整体宽度：37.7%。
- 整体高度：5.4%。
- 整体主体范围：X=31.7%～69.4%，Y=81.9%～87.2%。
- 核心白色血槽范围：X=35.6%～65.7%，Y=84.2%～85.5%。
- 血条水平居中放置于画面下方。
- 不添加 Boss 名称、头像、等级、图标、彩色填充或额外装饰框。

游玩界面的固定图层顺序为：

```text
场景背景 → 悟空人物 → 可选白色 Boss 血条 → 固定操作 HUD
```

## 操作 UI 规则

游玩界面的操作 HUD 必须严格依照技能内置的 `assets/ui/play.png`：

- 不重新设计或临摹替代。
- 不增加、删除或移动组件。
- 不改变图标、按键符号和量表内容。
- 不改变大小关系、颜色、透明度和边缘留白。
- 不生成第二套重复 HUD。

其他模式同样使用各自固定 PNG 素材，不额外添加小地图、标题或无关界面。

## 美术效果要求

- 整体采用低曝光但暗部可读的深沉明暗关系。
- 使用冷暗、低饱和环境色，并以少量暖色形成视觉焦点。
- 光线优先采用侧逆光或顶部斜光，体积光必须具有明确来源。
- 强化毛发、布料、金属磨损、石材风化、泥土和积雪等写实材质。
- 保持近景清晰、中景可读、远景受雾气和空气透视影响。
- 避免过度 HDR、死黑暗部、蓝紫霓虹、塑料皮肤、镜面盔甲和无来源粒子。

## 输出检查

生成完成后，应重点检查：

1. 图片是否为 1920×1080、16:9，主体是否完整且没有拉伸。
2. 是否正确执行所选模式的人物规则。
3. 悟空的位置、尺寸、接触阴影和场景融合是否准确。
4. 游玩界面 HUD 是否与固定 PNG 保持一致。
5. Boss 血条是否只在满足条件时出现，并符合固定坐标和尺寸。
6. 得胜界面和角色入场中的旧名称是否已完全替换。
7. 是否出现重复人物、重复 HUD、乱码或无关标题。

## 常见问题

### 为什么游戏截图模式没有操作 HUD？

“游戏截图”模式只使用左下角游戏水印。需要完整操作 HUD 时请选择“游玩界面”。

### 为什么没有 Boss 血条？

Boss 血条只用于“游玩界面”，且输入画面中必须存在与玩家悟空相互独立的明确敌方主体。广阔风景或普通探索场景不会添加。

### 可以同时置入多个悟空吗？

不可以。游玩界面和需要人物的游戏截图每张图只置入一名悟空。

### 可以修改操作 UI 的颜色或图标吗？

不可以。操作 UI 被视为冻结素材，必须保持预设内容、布局和视觉关系。
